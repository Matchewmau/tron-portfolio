# Soundtrack Audio Drop-In

Place an MP3 file named **`end-of-line.mp3`** inside this folder (`public/audio/end-of-line.mp3`) to stream your local Daft Punk — *End of Line* audio track directly through the portfolio's real-time Web Audio `AnalyserNode` and background synthwave visualizer.

When `public/audio/end-of-line.mp3` is not present, the portfolio automatically synthesizes an F-minor 116 BPM *"End of Line"*-inspired Web Audio synth & bassline sequence synced to the background wave visualizer.
